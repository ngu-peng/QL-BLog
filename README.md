# QL-BLog

一个简化版的微博式本地日志应用：**纯 HTML + CSS + JavaScript**，无后端、无框架、无构建工具，数据保存在浏览器 Local Storage 中。

## 如何打开

直接用浏览器打开 `index.html` 即可（双击文件，或在浏览器地址栏输入文件路径）。不需要启动任何服务器。

> 推荐使用 Chrome / Edge / Firefox 等现代浏览器。

## 功能清单

- **发布日志**：填写可选标题 + 正文（500 字以内），点击「发 布」按钮，或按 `Ctrl + Enter` 快捷发布
- **查看日志**：按时间倒序展示，每条显示标题、正文、发布时间和字数
- **编辑日志**：点击卡片右上角「编辑」，修改后点「保存」（或「取消」放弃）
- **删除日志**：点击「删除」，确认后删除单条日志
- **清空全部**：页面底部按钮，一键清空所有日志（不可恢复，有二次确认）
- **空内容保护**：正文为空时发布按钮禁用，无法发布空日志
- **数据持久化**：刷新页面、关闭浏览器后重新打开，日志依然存在

## 数据存储说明

- 所有日志以 JSON 数组形式保存在 **Local Storage** 中，key 为 `ql-blog-posts`
- 数据保存在**当前浏览器的当前计算机**上：换浏览器、换设备、清除浏览器数据（"清除浏览记录与网站数据"）都会丢失日志
- 想备份数据：在浏览器开发者工具（F12）→ Application（应用）→ Local Storage 中，复制 `ql-blog-posts` 的值即可
- 想彻底删除数据：点击页面底部「清空全部日志」，或在开发者工具中删除该 key

## 代码导读（给新手）

`app.js` 的阅读顺序建议：

1. **数据层** `load()` / `save()` —— 唯一和 Local Storage 打交道的地方
2. **状态** 全局变量 `posts` 数组 —— 所有日志都在这里
3. **渲染** `render()` —— 把 `posts` 数组画成页面卡片（数组变了就重画一遍）
4. **操作** `publish()` / `startEdit()` / `removePost()` / `clearAll()` —— 只修改 `posts` 数组，然后调用 `save() + render()`

核心思想一句话：**用户操作只改内存数组，改完统一持久化并重绘页面**。
